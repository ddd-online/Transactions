## [1.0.2] - 2026-10-22

### 调整

- 配置文件改为 `~/.tr.json`（开发版 `~/.tr-dev.json`），不再读写旧版 `.transactions.json`
- 两个版本可并存，互不影响现有配置与工作空间

## [1.0.1] - 2026-10-22

### 修复

- 窗口尺寸/位置超出屏幕时自动夹回工作区，右上角三键不再跑到屏外
- 设置页内容可滚动，旧数据导入入口直接可见
- 工作空间选择界面允许直接关闭窗口

## [1.0.0] - 2026-10-21

### 新增

- 全新 Electron + React 19 版本，覆盖记账、股票、事件、日记、待办
- 一次性旧版导入向导：检查 0.20.0 库、复制资产、校验金额
- 提供 NSIS 安装版与便携版，支持应用内检查更新

### 调整

- 技术栈由 Tauri + Rust + Leptos 迁移到 Electron + TypeScript
- 数据库改为 `node:sqlite`，金额仍以整数分存储，股票价格仍以厘存储

### 优化

- 页面改为侧栏分页加载，长列表与表单不再挤在单页
- 导入期间显示阶段进度，完成后自动打开新工作空间
