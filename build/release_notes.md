## [1.0.0] - 2026-10-25

### 新增

- 股票模块：账户（追加本金 / 支取 / 利息归本 / 资金变化记录）、持仓（建仓 / 加仓 / 减仓 / 清仓四类成交弹窗，含费用与成交明细）、记录（轮次列表、成交明细、轮次复盘与每日复盘）、统计（七项指标曲线与明细表）、设置（交易标签、复盘模板、交易费用、归档、重置）
- 待办重做：单列看板、新建弹窗、事项进度记录、历史表
- 事件：按年份浏览、卡片与详情、图片（主图与缩略图）、关联交易
- 日记：按账本隔离的纯文本日记，心情、字数、按年 / 月 / 日浏览，导出与导入 txt
- 导入旧版数据：从旧工作空间导入到新目录，带进度与导入报告
- 应用内检查更新：检查、下载进度与失败提示
- 账本菜单悬停显示账本描述

### 优化

- 排版：显式指定中文字面，中英与中数混排由排版引擎自动留隙，数字统一等宽
- 分析：图表提示框只保留一套数据、金额统一两位小数；图表不再随页面的无关重渲染而整张重建
- 股票：账户与资金记录表固定表头、行高与记录表一致、列宽随窗口收放；统计页汇总改为两行四列
- 设置：交易标签、复盘模板、每日复盘模板与交易费用改为弹窗编辑
- 打磨：按钮、分页与时间范围控件统一使用 2px 主色焦点环；图标按钮与分页箭头补中文可读名；标签芯片删除、关于页外链的点击热区扩到 24px
