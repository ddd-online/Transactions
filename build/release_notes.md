## [1.19.0] - 2026-11-04

### 新增

- 分析：饼图进场改成**扇区扫出** —— 每一片从自己的起始角展开到结束角，620ms、与折线描线同一条缓动；换分组或换时间范围时重扫一次，换主题只换颜色、不重扫
- 分析 / 股票：折线与股票统计曲线上的采样点改成**小实心圆**，与它那条线同色 —— 此前是空心的白环，看着像还没加载完

### 改进

- 图表色板换成**九条色相、每条只出现一次**：支出红 / 收入绿 / 转账蓝在前三位（与记录页的金额同色相），其余是它们之间的过渡色（橙 / 黄 / 青 / 天蓝 / 洋红 / 紫）。折线图与饼图共用这一套 —— 第 N 条曲线 / 第 N 名 = 第 N 色
- 色板补上了黄色，也去掉了容易混的颜色：任意两条至少差 24° 色相、相邻两位 ΔE76 ≥30；不再有藏青 / 酒红 / 墨绿那一档深色（最深的一条对画布 4.3:1）
- 饼图的折叠上限从 10 组改成 **9 组**：色板正好 9 个位置，宁可少画一片，也不让两片同色

### 修复

- 分析：饼图扇区此前按 95% 的填充不透明度绘制，比它自己的图例点浅一档（`#d27369` 画成了 `#d4746a`），对画布的对比度也一起掉到 3:1 以下 —— 现在按令牌原值填满
- 分析：饼图色板此前在同一色相里分两档（两个绿只差 14°），低色度下分不出来 —— 改成一个色相只占一个位置
