## [1.20.0] - 2026-11-05

### 改进

- **启动更快。** 页面改成按需加载：入口从 6.5MB 降到 2.4MB，图表引擎（约 2.7MB）只在打开分析页 / 股票统计时才载入。
- **股票统计页更顺。** 切到统计页的脚本开销从 103ms 降到 44ms；「最近 N 笔」不再每敲一位就重算一次（三位数 101ms → 44ms）；展开的大图关掉即销毁，之后换指标只重画一张。
- **描线动画按采样密度决定播不播。** 十几个点照旧沿路径画出来；上百个采样直接画完 —— 数据是同一份，只是不再为看不出的动画反复重绘整块画布。
- **悬停与按下重新取值。** 白字压在实色按钮上，往亮走就掉出 4.5:1；现在三种状态在浅色与深色下都落在 5.1–9.4:1，深色下按钮也不会在悬停时沉进背景。

### 可访问性

- 三级灰提到 4.5:1（`#6b7078`），日期选择器的星期行、图表提示、时间戳这些 11–12px 小字不再发灰。
- 事件图片画廊的缩略图改成真按钮：键盘能 Tab 到、Enter 能切，读屏听到「查看第 N 张图片，共 M 张」和当前选中态。
- **31 处错误提示接上读屏播报**；8 个单字段表单的错误与出错的那个输入框双向关联，焦点回到框里也听得到原因。
- 减少动态偏好下，加载指示器不再冻成静帧（换成不位移的明暗呼吸）；描线动画则直接关掉。
- 缩略图的焦点环改成双环（墨色 + 主色），压在照片上也分得开。
- 事件身份色里两档提到达标（土黄 2.57:1 → 3.36:1、橘黄 2.72:1 → 3.39:1），深色下随主题提亮一档。

### 修复

- **某一页的代码文件读不到时不再整窗白屏**：只有那一页变成「这一页没有加载出来」，给出「重新加载」与「关闭窗口」两条路，外壳、导航、账本都还在。
- 深色下实色危险按钮的白字只有 2.8:1 —— 改用墨色后 5.2:1；主按钮悬停的 3.24:1 已修正到 6.1:1。
- 深色下事件卡的身份色此前不随主题走，现在与账本身份色同一条规矩。
- 「费用」与「费用合计」上两处只对鼠标生效的说明，改成可见文案。
